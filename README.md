# Research Ops Claude Skills

Claude Code skills for the Instacart Research Operations team (Megan Aguilar, Anna Ma, Emanuelle Bastien).

## What this is

Each folder under `skills/` contains a `SKILL.md` file — a set of instructions Claude follows when a skill is invoked. Skills are organized by category, matching the [Skills Proposal doc](https://docs.google.com/document/d/19BzSFHktidEvpclcArfo_ijG3tPYODgUnTbGaNpiW3o/edit).

All skills reference the [Research Ops Main Doc](https://docs.google.com/document/d/1jzoICKM6iQxlfHam44rkPILhBm9NdS1aZxiBSoCZnCw/edit) as the source of truth for process, SLAs, and linked documentation.

## How to use a skill

Paste the relevant content (research request, screener, brief, etc.) into Claude Code, then type the skill command. Claude will follow the skill's workflow and produce a structured output ready to use or share.
