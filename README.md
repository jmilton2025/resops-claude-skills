# Research Ops Claude Skills

Claude Code skills for the Instacart Research Operations team (Megan Aguilar, Anna Ma, Emanuelle Bastien).

## What this is

Each folder under `skills/` contains a `SKILL.md` file — a set of instructions Claude follows when a skill is invoked. These skills are designed to reduce manual effort across the research recruitment lifecycle.

## Skills

| Skill | Command | Category | Status |
|---|---|---|---|
| Intake & Triage | `/resops-intake-triage` | Intake & Triage | ✅ Live |

## How to use a skill

Paste a research request into Claude Code, then type the skill command (e.g. `/resops-intake-triage`). Claude will parse the request, flag gaps, draft a follow-up message, and generate a kickoff agenda.
